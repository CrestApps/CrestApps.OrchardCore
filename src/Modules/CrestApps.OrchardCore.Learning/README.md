# Learning

| Feature | Id | What it adds |
| --- | --- | --- |
| Learning | `CrestApps.OrchardCore.Learning` | The Course type and Page, Video, File, Link and Acknowledgement lessons contained in it; the course outline of sections; enrollments with grants, statuses and history; progress and completion with a snapshot; release rules and completion rules; the content access handler that keeps lessons and their Secure Media files from people who are not enrolled; the enrollment admin pages; permissions and the Learning roles, setup, catalog and public media recipes; workflows, the Learning data source and Enroll learners pipeline step, reports, notifications, Audit Trail events, webhooks and the personal-data contributor (each when its feature is on); the LearningEnrollments recipe and deployment steps. |
| Learner Pages | `CrestApps.OrchardCore.Learning.LearnerPages` | My learning, the transcript, the player, and the course page outline with its Enroll or Continue button. |
| Self Enrollment | `CrestApps.OrchardCore.Learning.SelfEnrollment` | Enrolling on the course page: at once, with the enrollment key, or pending approval. |

See the [Learning documentation](../../CrestApps.Docs/docs/modules/learning.md).
