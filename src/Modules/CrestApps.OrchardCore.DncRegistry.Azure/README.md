# DNC Registry - Azure Blob Storage

Stores uploaded Local DNC Registry files in Azure Blob Storage instead of the local file system.

## Features

| Feature | Id | Description |
| --- | --- | --- |
| DNC Registry - Azure Blob Storage | `CrestApps.OrchardCore.DncRegistry.Azure` | Stores uploaded Local DNC Registry files in Azure Blob Storage instead of the local file system. |

Enable a feature under **Configuration > Features**, or with the `Feature` step of a recipe.

## Dependencies

Enabling a feature of this module enables the features it depends on:

- `CrestApps.OrchardCore.DncRegistry.Local`
