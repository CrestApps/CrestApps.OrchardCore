# Digital Downloads

Delivers digital products: files kept privately on each product, downloaded by buyers through expiring links with a download limit, on their order page and in the confirmation email.

## Features

| Feature | Id | Description |
| --- | --- | --- |
| Digital Downloads | `CrestApps.OrchardCore.Downloads` | Delivers digital products: files kept privately on each product, downloaded by buyers through expiring links with a download limit, on their order page and in the confirmation email. |

Enable a feature under **Configuration > Features**, or with the `Feature` step of a recipe.
