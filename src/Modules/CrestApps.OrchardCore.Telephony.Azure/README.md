# Telephony - Azure Blob Storage

Stores Contact Center call recordings in Azure Blob Storage, keeping the same encryption-at-rest as the local store.

## Features

| Feature | Id | Description |
| --- | --- | --- |
| Telephony - Azure Blob Storage | `CrestApps.OrchardCore.Telephony.Azure` | Stores Contact Center call recordings in Azure Blob Storage, keeping the same encryption-at-rest as the local store. |

Enable a feature under **Configuration > Features**, or with the `Feature` step of a recipe.

## Dependencies

Enabling a feature of this module enables the features it depends on:

- [`CrestApps.OrchardCore.Telephony`](../CrestApps.OrchardCore.Telephony/README.md)
