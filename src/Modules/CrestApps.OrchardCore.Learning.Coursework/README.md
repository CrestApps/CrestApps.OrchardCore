# CrestApps.OrchardCore.Learning.Coursework

Coursework for the CrestApps Learning module.

- **Coursework course item**: instructions, a due date with late marking, text or file hand-ins with file types, sizes and counts, and resubmission until graded.
- **Rubrics**: content items with criteria and levels worth points; the grade is the chosen levels out of the best of each criterion.
- **Submissions**: kept per enrollment with attempt numbers; files go to the protected file store and open only to the learner and their graders.
- **Grading**: grade against a rubric or out of points with feedback, return for resubmission, regrade with a reason that keeps the earlier grade; the grade reaches the course grade.
- **Grading list**: submissions appear beside quiz attempts in the Learning grading list through `IGradingQueueSource`.
- **Integrations**: Coursework Submitted and Coursework Graded workflow events, the Return Coursework For Resubmission task, the Learning coursework data source, the `LearningSubmissions` recipe and deployment steps, and personal data.

See the [Learning Coursework documentation](https://orchardcore.crestapps.com/docs/modules/learning-coursework).
