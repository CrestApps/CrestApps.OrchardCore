# OR-Tools

Google OR-Tools solvers for Workforce and Dispatch: **OR-Tools Shift Scheduling** auto-schedules shifts with a CP-SAT model, and **OR-Tools Dispatch** optimizes a dispatch day with the routing solver. Each starts from the built-in solver's answer and keeps the better one.

This module isn't in the CrestApps CMS targets, because OR-Tools ships native libraries for every platform; add the package to your application to use it.

See the [OR-Tools documentation](../../CrestApps.Docs/docs/modules/or-tools.md).
