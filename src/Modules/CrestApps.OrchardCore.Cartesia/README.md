# Cartesia

Cartesia voices for speech, with emotion, a voice library and cloning, and speech recognition. Add a speech deployment with the Cartesia API key.

## Features

| Feature | Id | Description |
| --- | --- | --- |
| Cartesia | `CrestApps.OrchardCore.Cartesia` | Cartesia voices for speech, with emotion, a voice library and cloning, and speech recognition. Add a speech deployment with the Cartesia API key. |

Enable a feature under **Configuration > Features**, or with the `Feature` step of a recipe.
