# CrestApps.OrchardCore.Learning.Classes

Classes for the CrestApps Learning module.

- **Class course item**: "attend a class", with the Scheduling appointment type and resources of its sessions, the defaults of new sessions and the minutes a partial attendance needs.
- **Sessions**: dated Scheduling sessions of a class, with meetings, a capacity, a location or a meeting link, a registration window and a waitlist mode.
- **Registration**: an enrolled learner registers for one session from the learner player, waits when it is full, and accepts an offered place or gives up a place.
- **Roster and attendance**: staff mark attendance in bulk; attendance that counts completes the class item.

See the [Learning Classes documentation](https://orchardcore.crestapps.com/docs/modules/learning-classes).
