# Reports (OpenXml)

Adds Excel (.xlsx) exports to the Reports framework using Open XML.

## Features

| Feature | Id | Description |
| --- | --- | --- |
| Reports (OpenXml) | `CrestApps.OrchardCore.Reports.OpenXml` | Adds Excel (.xlsx) workbook exports to the Reports area using Open XML. |

Enable a feature under **Configuration > Features**, or with the `Feature` step of a recipe.

## Dependencies

Enabling a feature of this module enables the features it depends on:

- [`CrestApps.OrchardCore.Reports`](../CrestApps.OrchardCore.Reports/README.md)
