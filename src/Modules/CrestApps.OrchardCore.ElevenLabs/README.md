# ElevenLabs

ElevenLabs voices for speech, with a voice library and cloning, and Scribe speech recognition. Add a speech deployment with the ElevenLabs API key.

## Features

| Feature | Id | Description |
| --- | --- | --- |
| ElevenLabs | `CrestApps.OrchardCore.ElevenLabs` | ElevenLabs voices for speech, with a voice library and cloning, and Scribe speech recognition. Add a speech deployment with the ElevenLabs API key. |

Enable a feature under **Configuration > Features**, or with the `Feature` step of a recipe.
