# Enhanced Roles

Extends Orchard Core Roles module by providing other services like role-part.

## Features

| Feature | Id | Description |
| --- | --- | --- |
| Enhanced Roles | `CrestApps.OrchardCore.Roles` | Extends Orchard Core Roles module by providing other services like role-part. |

Enable a feature under **Configuration > Features**, or with the `Feature` step of a recipe.

## Dependencies

Enabling a feature of this module enables the features it depends on:

- `OrchardCore.Roles`
- `OrchardCore.Resources`
