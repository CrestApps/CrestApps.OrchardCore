# AI Documents (OpenXml)

Extends the 'AI Documents' feature by allowing OpenXml file (i.e., .docx, .xlsx, .pptx).

## Features

| Feature | Id | Description |
| --- | --- | --- |
| AI Documents (OpenXml) | `CrestApps.OrchardCore.AI.Documents.OpenXml` | Extends the 'AI Documents' feature by allowing OpenXml file (i.e., .docx, .xlsx, .pptx). |

Enable a feature under **Configuration > Features**, or with the `Feature` step of a recipe.
