# AI Data Sources

Provides AI data source management, knowledge base indexing, and RAG search capabilities.

## Features

| Feature | Id | Description |
| --- | --- | --- |
| AI Data Sources | `CrestApps.OrchardCore.AI.DataSources` | Provides AI data source management, knowledge base indexing, and RAG search capabilities. Enabled by the features that depend on it. |

Enable a feature under **Configuration > Features**, or with the `Feature` step of a recipe.

## Dependencies

Enabling a feature of this module enables the features it depends on:

- [`CrestApps.OrchardCore.AI`](../CrestApps.OrchardCore.AI/README.md)
- `OrchardCore.Indexing`
