# Product Search (Elasticsearch)

Lets product listings search an Elasticsearch index: keyword relevance, filter counts, ranges and sorts for large catalogs.

## Features

| Feature | Id | Description |
| --- | --- | --- |
| Product Search (Elasticsearch) | `CrestApps.OrchardCore.Products.Elasticsearch` | Lets product listings search an Elasticsearch index: keyword relevance, filter counts, ranges and sorts for large catalogs. |

Enable a feature under **Configuration > Features**, or with the `Feature` step of a recipe.

## Dependencies

Enabling a feature of this module enables the features it depends on:

- `CrestApps.OrchardCore.Products.Listing`
- `OrchardCore.Elasticsearch`
