# Bookings

Sells bookings: fixed departures such as tours and classes, nightly stays such as rooms and rentals, and time slots such as appointments, each with its capacity per date, prices per person or per room, a deposit with the balance charged to the saved card later, cancellation policies, requests the store confirms before the buyer pays, travelers' details, and a calendar of what's booked.
