# AI Documents indexing using Azure AI Search

Provides services to index AI Documents in Azure AI Search indexes.

## Features

| Feature | Id | Description |
| --- | --- | --- |
| AI Documents indexing using Azure AI Search | `CrestApps.OrchardCore.AI.Documents.AzureAI` | Provides services to index AI Documents in Azure AI Search indexes. |

Enable a feature under **Configuration > Features**, or with the `Feature` step of a recipe.

## Dependencies

Enabling a feature of this module enables the features it depends on:

- [`CrestApps.OrchardCore.AI.Documents`](../CrestApps.OrchardCore.AI.Documents/README.md)
- `OrchardCore.Indexing`
- `OrchardCore.AzureAI`
