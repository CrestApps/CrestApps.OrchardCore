# CrestApps.OrchardCore.Learning.Programs

Learning paths and required learning for the CrestApps Learning module.

- **Learning Paths**: ordered course sets joined by then, and and or; each set is completed by every course, any one or a number of them, and each completed stage enrolls the next.
- **Required Learning**: a course, a learning path or a certification path required of a user audience or named people, with a due date, reminders, escalation to the manager, exemptions with protected evidence, a nightly run and Run now.
- **Team Learning**: the required learning of the people who report to a manager.

See the [Learning Programs documentation](https://orchardcore.crestapps.com/docs/modules/learning-programs).
