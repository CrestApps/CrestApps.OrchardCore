# AI Documents indexing using Elasticsearch

Provides services to index AI Documents in Elasticsearch indexes.

## Features

| Feature | Id | Description |
| --- | --- | --- |
| AI Documents indexing using Elasticsearch | `CrestApps.OrchardCore.AI.Documents.Elasticsearch` | Provides services to index AI Documents in Elasticsearch indexes. |

Enable a feature under **Configuration > Features**, or with the `Feature` step of a recipe.

Enabling a feature of this module enables the features it depends on:
