# AI Memory

Provides persistent, user-scoped AI memory for AI profiles and chat interactions.

## Features

| Feature | Id | Description |
| --- | --- | --- |
| AI Memory | `CrestApps.OrchardCore.AI.Memory` | Provides persistent, user-scoped AI memory for AI profiles and chat interactions. Enabled by the features that depend on it. |

Enable a feature under **Configuration > Features**, or with the `Feature` step of a recipe.

## Dependencies

Enabling a feature of this module enables the features it depends on:

- `CrestApps.OrchardCore.AI.Chat.Core`
- `OrchardCore.Indexing`
