# AI Data Sources - Elasticsearch

Adds Elasticsearch support for AI data source document embeddings, vector search, and indexing.

## Features

| Feature | Id | Description |
| --- | --- | --- |
| AI Data Sources - Elasticsearch | `CrestApps.OrchardCore.AI.DataSources.Elasticsearch` | Adds Elasticsearch support for AI data source document embeddings, vector search, and indexing. |

Enable a feature under **Configuration > Features**, or with the `Feature` step of a recipe.

## Dependencies

Enabling a feature of this module enables the features it depends on:

- [`CrestApps.OrchardCore.AI.DataSources`](../CrestApps.OrchardCore.AI.DataSources/README.md)
- `OrchardCore.Elasticsearch`
