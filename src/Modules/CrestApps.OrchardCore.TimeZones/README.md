# Time Zones

Provides friendly named time zone maps and time zone picker services.

## Features

| Feature | Id | Description |
| --- | --- | --- |
| Time Zones | `CrestApps.OrchardCore.TimeZones` | Provides friendly named time zone maps, picker services, recipe import, and deployment export support. |

Enable a feature under **Configuration > Features**, or with the `Feature` step of a recipe.

## Dependencies

Enabling a feature of this module enables the features it depends on:

- `OrchardCore.Recipes.Core`
