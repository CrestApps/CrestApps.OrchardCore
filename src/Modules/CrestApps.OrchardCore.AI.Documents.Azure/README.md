# AI Documents - Azure Blob Storage

Stores uploaded AI documents in Azure Blob Storage using Orchard Core file storage abstractions.

## Features

| Feature | Id | Description |
| --- | --- | --- |
| AI Documents - Azure Blob Storage | `CrestApps.OrchardCore.AI.Documents.Azure` | Stores uploaded AI documents in Azure Blob Storage using Orchard Core file storage abstractions. |

Enable a feature under **Configuration > Features**, or with the `Feature` step of a recipe.

## Dependencies

Enabling a feature of this module enables the features it depends on:

- [`CrestApps.OrchardCore.AI.Documents`](../CrestApps.OrchardCore.AI.Documents/README.md)
