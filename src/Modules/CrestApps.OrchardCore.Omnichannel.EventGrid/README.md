# Omnichannel - Azure Event Grid

Receives authenticated Azure Event Grid events and dispatches them through the Omnichannel event pipeline.

## Features

| Feature | Id | Description |
| --- | --- | --- |
| Omnichannel - Azure Event Grid | `CrestApps.OrchardCore.Omnichannel.EventGrid` | Receives authenticated Azure Event Grid events and dispatches them through the Omnichannel event pipeline. |

Enable a feature under **Configuration > Features**, or with the `Feature` step of a recipe.

## Dependencies

Enabling a feature of this module enables the features it depends on:
