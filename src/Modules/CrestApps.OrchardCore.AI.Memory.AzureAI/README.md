# AI Memory indexing using Azure AI Search

Provides services to index AI memory in Azure AI Search indexes.

## Features

| Feature | Id | Description |
| --- | --- | --- |
| AI Memory indexing using Azure AI Search | `CrestApps.OrchardCore.AI.Memory.AzureAI` | Provides services to index AI memory in Azure AI Search indexes. |

Enable a feature under **Configuration > Features**, or with the `Feature` step of a recipe.

## Dependencies

Enabling a feature of this module enables the features it depends on:

- [`CrestApps.OrchardCore.AI.Memory`](../CrestApps.OrchardCore.AI.Memory/README.md)
- `OrchardCore.Indexing`
- `OrchardCore.AzureAI`
