# Assets

| Feature | Id | What it adds |
| --- | --- | --- |
| Assets | `CrestApps.OrchardCore.Assets` | Asset types (category, attributes, meters), assets owned by the business, a customer or a company, with a hierarchy, location, warranty, documents, a vehicle's plate and VIN, and append-only meter readings. Assets other records use can't be deleted (`IAssetUsage`). |
| Fleet | `CrestApps.OrchardCore.Assets.Fleet` | Capacity and fuel, an Equipment calendar for each schedulable asset (no double-booking), and an Inventory location for a van that carries stock. |

See the [Assets documentation](../../CrestApps.Docs/docs/modules/assets.md).
