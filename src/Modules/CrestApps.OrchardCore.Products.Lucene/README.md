# Product Search (Lucene)

Lets product listings search a Lucene index: keyword relevance, filter counts, ranges and sorts, kept on the server's disk.

## Features

| Feature | Id | Description |
| --- | --- | --- |
| Product Search (Lucene) | `CrestApps.OrchardCore.Products.Lucene` | Lets product listings search a Lucene index: keyword relevance, filter counts, ranges and sorts, kept on the server's disk. |

Enable a feature under **Configuration > Features**, or with the `Feature` step of a recipe.

## Dependencies

Enabling a feature of this module enables the features it depends on:

- `CrestApps.OrchardCore.Products.Listing`
- `OrchardCore.Lucene`
