# AI File Sources

Adds a File AI data source populated by file sources. A file source reads a folder on a schedule and stores each file's text, figures, charts and tables as separately retrievable knowledge.

## Features

| Feature | Id | Description |
| --- | --- | --- |
| AI File Sources | `CrestApps.OrchardCore.AI.FileSources` | Adds a File AI data source populated by file sources. A file source reads a folder on a schedule and stores each file's text, figures, charts and tables as separately retrievable knowledge. |

Enable a feature under **Configuration > Features**, or with the `Feature` step of a recipe.
