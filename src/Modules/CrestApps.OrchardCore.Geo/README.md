# Geo

Geography for Orchard Core, shared by every module that works with places.

| Feature | Id | What it adds |
| --- | --- | --- |
| Geo, Maps and Territories | `CrestApps.OrchardCore.Geo` | Service territories (a shape on a map, postal codes, or both), the territory resolver, background geocoding with retries, the travel-time and route seams with the built-in haversine estimate, map settings and the `crestapps-map` Leaflet component. |

See the [Geo documentation](../../CrestApps.Docs/docs/modules/geo.md).
