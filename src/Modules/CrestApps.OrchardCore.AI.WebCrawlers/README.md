# AI Web Crawlers

Adds a Web AI data source populated by strategy-based web crawlers that scrape public websites (starting with sitemap discovery) and index each page into the AI Knowledge Base for RAG.

## Features

| Feature | Id | Description |
| --- | --- | --- |
| AI Web Crawlers | `CrestApps.OrchardCore.AI.WebCrawlers` | Adds a Web AI data source populated by strategy-based web crawlers that scrape public websites (starting with sitemap discovery) and index each page into the AI Knowledge Base for RAG. |

Enable a feature under **Configuration > Features**, or with the `Feature` step of a recipe.

## Dependencies

Enabling a feature of this module enables the features it depends on:
