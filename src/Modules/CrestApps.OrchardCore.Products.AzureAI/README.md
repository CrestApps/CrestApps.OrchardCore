# Product Search (Azure AI Search)

Lets product listings search an Azure AI Search index: keyword relevance, filter counts, ranges and sorts, hosted by Azure.

## Features

| Feature | Id | Description |
| --- | --- | --- |
| Product Search (Azure AI Search) | `CrestApps.OrchardCore.Products.AzureAI` | Lets product listings search an Azure AI Search index: keyword relevance, filter counts, ranges and sorts, hosted by Azure. |

Enable a feature under **Configuration > Features**, or with the `Feature` step of a recipe.

## Dependencies

Enabling a feature of this module enables the features it depends on:

- `CrestApps.OrchardCore.Products.Listing`
- `OrchardCore.Indexing`
- `OrchardCore.AzureAI`
