# AI Memory indexing using Elasticsearch

Provides services to index AI memory in Elasticsearch indexes.

| --- | --- | --- |
| AI Memory indexing using Elasticsearch | `CrestApps.OrchardCore.AI.Memory.Elasticsearch` | Provides services to index AI memory in Elasticsearch indexes. |
