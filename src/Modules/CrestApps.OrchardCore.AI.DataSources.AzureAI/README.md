# AI Data Sources - Azure AI Search

Adds Azure AI Search support for AI data source document embeddings, vector search, and indexing.

## Features

| Feature | Id | Description |
| --- | --- | --- |
| AI Data Sources - Azure AI Search | `CrestApps.OrchardCore.AI.DataSources.AzureAI` | Adds Azure AI Search support for AI data source document embeddings, vector search, and indexing. |

Enable a feature under **Configuration > Features**, or with the `Feature` step of a recipe.

## Dependencies

Enabling a feature of this module enables the features it depends on:

- [`CrestApps.OrchardCore.AI.DataSources`](../CrestApps.OrchardCore.AI.DataSources/README.md)
- `OrchardCore.Indexing`
- `OrchardCore.AzureAI`
