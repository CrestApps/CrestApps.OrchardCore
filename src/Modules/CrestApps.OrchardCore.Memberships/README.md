# Memberships

Sells memberships: a product whose purchase puts the buyer in roles for a year, a month or for good, so content gated by those roles with Content Access Control opens to them. A refund, a cancellation or the end date takes them out again, and buying again adds time.

A refund, a cancellation or the end date takes them out again, and buying again adds time. |
