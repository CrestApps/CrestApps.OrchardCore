# Learning Certifications

| Feature | Id | What it adds |
| --- | --- | --- |
| Learning Certifications | `CrestApps.OrchardCore.Learning.Certifications` | Certification paths on the Skills certification editor (course completed and assessment passed requirements, expiry from the completion date, the previous expiry or a fixed day, renewal window and grace period), progress with every cycle and its evidence, idempotent issue and renewal through the Skills issuer, the renewal queue and the hourly upkeep, the people on each path, My certifications, revoking from an enrollment review, and (each when its feature is on) notifications, workflows, the Certification compliance report, the Learning certifications data source, the LearningCertificationPaths recipe and deployment steps, the personal-data contributor and telemetry. |

Depends on Learning and Skills: Issued Certificates. With Learning Assessments on, a passed quiz can be a requirement.

See the [Learning certifications documentation](../../CrestApps.Docs/docs/modules/learning-certifications.md).
