# Learning Assessments

| Feature | Id | What it adds |
| --- | --- | --- |
| Learning Assessments | `CrestApps.OrchardCore.Learning.Assessments` | Question banks with nine question types, the Quiz course item with fixed and random questions, self-contained attempts, deadlines kept by the server, the exam player, grading of essays, regrades, voids and overrides with a reason, quiz access codes, the grading pages, item analysis, and (each when its feature is on) workflows, the Learning assessments data source, the quiz results report, notifications, Audit Trail events, webhooks, ContentTransfer question import, the personal-data contributor and the LearningAttempts and LearningGradeScales recipe and deployment steps. |
| Learning Gradebook | `CrestApps.OrchardCore.Learning.Assessments.Gradebook` | Grade scales and the gradebook of each course. |

See the [Learning assessments documentation](../../CrestApps.Docs/docs/modules/learning-assessments.md).
