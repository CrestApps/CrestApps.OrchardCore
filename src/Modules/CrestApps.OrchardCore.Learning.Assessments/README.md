# Learning Assessments

| Feature | Id | What it adds |
| --- | --- | --- |
| Learning Assessments | `CrestApps.OrchardCore.Learning.Assessments` | The Quiz course item. Each quiz owns a survey of kind Quiz in Surveys, which holds its questions, attempts (survey responses), scoring and grading; the quiz records the course item result from the learner's responses. Also the LMS grading page (the Surveys grading queue next to Coursework submissions), and the LearningGradeScales recipe and deployment steps. |
| Learning Gradebook | `CrestApps.OrchardCore.Learning.Assessments.Gradebook` | Grade scales and the gradebook of each course. |

See the [Learning assessments documentation](../../CrestApps.Docs/docs/modules/learning-assessments.md).
