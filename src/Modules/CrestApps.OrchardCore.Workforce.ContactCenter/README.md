# Workforce for Contact Center

Contact center workforce management on the Workforce module: a worker for every agent, punches from agent sign-in, and real-time and daily adherence.

## Features

| Feature | Feature ID | Purpose |
| --- | --- | --- |
| Workforce for Contact Center | `CrestApps.OrchardCore.Workforce.ContactCenter` | A worker for every agent, linked through the user account. |
| Contact Center Sign-in Punches | `CrestApps.OrchardCore.Workforce.ContactCenter.SignInPunches` | Clocks agents in and out when they sign in and out. |
| Workforce Forecasting | `CrestApps.OrchardCore.Workforce.Forecasting` | Forecasts of planning groups of queues, Erlang C and Erlang A staffing, and the active forecast as the team's coverage. |
| Workforce Intraday | `CrestApps.OrchardCore.Workforce.Intraday` | The day as it happens, reforecasts, the quietest times, and voluntary overtime and time off taken in My Work. |
| Workforce Adherence | `CrestApps.OrchardCore.Workforce.Adherence` | The real-time board, alerts, daily adherence and conformance, exceptions, rule sets and report data sets. |
