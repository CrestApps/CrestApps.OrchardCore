# Dispatch

| Feature | Id | What it adds |
| --- | --- | --- |
| Dispatch | `CrestApps.OrchardCore.Dispatch` | A visit for each work order; technicians found by skills, certifications, territory, shifts, time off and travel and ranked by weights; assignment under a lock per technician that never double-books, with a job on their team calendar; field statuses that move the work order along; the dispatch board with a timeline, the unscheduled queue and a map, live over SignalR; dispatch settings; workflow events. |

See the [Dispatch documentation](../../CrestApps.Docs/docs/modules/dispatch.md).
