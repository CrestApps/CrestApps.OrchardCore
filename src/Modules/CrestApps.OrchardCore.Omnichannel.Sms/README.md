# SMS Omnichannel Automation

Handles automated omnichannel activities through the configured Orchard Core SMS provider.

## Features

| Feature | Id | Description |
| --- | --- | --- |
| SMS Omnichannel Automation | `CrestApps.OrchardCore.Omnichannel.Sms` | Handles automated omnichannel activities through the configured Orchard Core SMS provider. |

Enable a feature under **Configuration > Features**, or with the `Feature` step of a recipe.

## Dependencies

Enabling a feature of this module enables the features it depends on:

- [`CrestApps.OrchardCore.AI`](../CrestApps.OrchardCore.AI/README.md)
- `CrestApps.OrchardCore.AI.Chat.Core`
- [`CrestApps.OrchardCore.Omnichannel.Managements`](../CrestApps.OrchardCore.Omnichannel.Managements/README.md)
- `OrchardCore.Sms`
- `CrestApps.OrchardCore.ContactCenter.BusinessHours`
- `CrestApps.OrchardCore.ContactCenter.ProviderInbox`
