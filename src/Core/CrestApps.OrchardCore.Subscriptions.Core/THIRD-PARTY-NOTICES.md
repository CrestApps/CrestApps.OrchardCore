## Public Suffix List

`Data/public_suffix_list.dat` is the Public Suffix List (<https://publicsuffix.org>), ICANN and private sections, as
served from <https://publicsuffix.org/list/public_suffix_list.dat>. The file's header records the version it was
retrieved at.

The list is maintained by the Public Suffix List project and its contributors, and is subject to the terms of the
Mozilla Public License, v. 2.0 (MPL-2.0): <https://mozilla.org/MPL/2.0/>. The file is shipped unmodified, with its
license notice, as a resource embedded in this assembly; its source is the file itself and the URL above.

`utilities/public-suffix-list/update-public-suffix-list.mjs` in the CrestApps.OrchardCore repository refreshes it.
