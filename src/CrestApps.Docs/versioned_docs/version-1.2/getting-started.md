# Getting Started with CrestApps.OrchardCore 1.2

Install the package for each module you want to use in your Orchard Core web application, then enable the matching feature from **Tools -> Features** in the Orchard admin.

Version 1.2 targets `net8.0` and `net9.0`, and the default development target framework was `net9.0`.

Most 1.2 documentation lived in module-level README files. Those README files are preserved in this documentation version under **AI**, **AI Providers**, and **Modules**.
