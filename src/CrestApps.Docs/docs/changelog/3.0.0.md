# Version 3.0.0 Release Notes

This page highlights the changes in the `3.0.0` line.

## AI Documents

### File upload security scanning through Orchard Core

The **AI Documents** module now routes every uploaded file through Orchard Core's shared [`FileCreationService`](https://docs.orchardcore.net/en/latest/reference/core/file-upload-security/) pre-storage pipeline before the file is stored or processed.

Highlights:

- Uploads from chat interactions, profiles, chat sessions, and widgets are scanned before storage.
- Enabling the `OrchardCore.Antivirus` feature adds **ClamAV** virus scanning to all AI document uploads with no additional code.
- Rejections are fail-closed and logged at `Warning` level.

See [AI Documents](../ai/documents) for details.

## Omnichannel Management

### Outbound and inbound activity logging from a contact

The contact **Activities** page replaces the single **New Activity** button with an **Add Activity** dropdown offering **Outbound** and **Inbound**.

Highlights:

- **Outbound** keeps the existing scheduled-activity behavior, but its subject selector now lists **outbound** subjects only, auto-selects the subject when exactly one exists, and warns (and blocks) when no outbound subject is configured.
- **Inbound** is a new screen that logs a **completed** activity for contact-initiated work. It mirrors the complete-activity UI (contact info, disposition, notes, and workflow-results preview) with an added subject selector limited to **inbound** subjects, auto-selecting the subject when only one exists. The subject's editable fields are rendered directly under the selector instead of in a separate subject-details card. The activity is recorded as completed by the current user and immediately runs the subject flow, which may create a follow-up activity. A warning is shown and logging is blocked when no inbound subject is configured.

See [Omnichannel Management](../omnichannel/management) for details.
