You change a survey in its draft. Publishing makes a numbered version that respondents see.

| | |
| --- | --- |
| **Menu** | **Surveys** → **Surveys**, then **Design** |
| **Permission** | Publish, restore and close surveys, or Publish, restore and close own surveys for your own surveys |
| **Feature** | Surveys |

<AskYourAdmin />

## Publish

1. In the designer, select **Save and publish** at the bottom of the page: it saves your changes, then opens the publish page. On the survey's other pages, select **Publish** in the header.
2. Fix the problems under **Fix these problems before publishing**, and read **Check these before publishing**.
3. Read **Changes since version** N. When a change affects existing answers, tick **I understand that some changes affect existing answers and comparisons**.
4. Enter **Notes** and select **Publish**.

The first publish opens the survey and makes its public link. People who already started keep the version they started on; results join the versions question by question.

**Discard draft** replaces the draft with the published version. If someone else changed the draft since you opened the page, nothing is replaced: reload and try again.

## Versions

Open the survey's menu and select **Versions**. Each version shows when it was published and by whom. View a version, compare it with the draft (**Compare with draft**), or restore a version into the draft and publish it again.

## Preview

Select **Preview** to try the draft as a respondent. Preview responses are marked as tests: they are left out of results and limits.
