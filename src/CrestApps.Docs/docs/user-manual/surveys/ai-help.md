Surveys AI helps you read answers, translate surveys and grade. A person always checks the result.

| | |
| --- | --- |
| **Menu** | **Surveys** → **Surveys**, then the survey's menu; **Surveys** → **Grading** |
| **Permission** | Manage own surveys, or Manage all surveys; Grade survey responses (or Grade responses of own surveys) for scoring help |
| **Feature** | Surveys AI |

<AskYourAdmin />

## Summarize answers

1. In the survey's menu, select **Summarize answers with AI**.
2. Pick the **Written question** and select **Summarize**.

The summary reads the latest answers and never names a respondent. Check it against the answers before you share it.

## Translate with AI

In the survey's menu, select **Translate with AI**, pick the language in **Translate into**, and select **Translate**. Tick **Replace existing translations** to translate every text again. Review the result on the **Translations** page (in the survey's side menu), then publish. If someone else changes the survey while it is being translated, nothing is saved; select **Translate** again.

## Suggest a score

On a grading page, select **Suggest a score with AI** next to an answer. The points and comment are filled in; change them as you see fit, then save.

## Ask the assistant

When your site has an AI assistant with the survey tools, you can ask it to list your surveys, sum up a survey's results, or draft a new survey for you to review. Results cover the published version. An anonymous survey shows no response count until it has enough responses to keep people from being singled out. A drafted survey is never published by the assistant.
