A saved view is a ready-made filter of the ticket list, such as **My open tickets** or **Unassigned**. Views show above the list, and selecting one fills in the list's filters.

| | |
| --- | --- |
| **Menu** | **Service Desk** → **Views** |
| **Permission** | Manage ticket settings |
| **Feature** | Tickets |

<AskYourAdmin />

## Add or edit a view

Go to **Service Desk** → **Views** and select **Add ticket view**, or a view to edit it.

| Field | What it does |
| --- | --- |
| **Name** | The name above the list |
| **Shared with** | A team. Leave empty to share the view with everybody |
| **Position** | Where the view is listed; lower comes first |
| **Status categories** | Leave all unchecked to list every category |
| **Desks** | Leave none selected to list every desk the user may see |
| **Assigned to** | **Anybody**, **The user looking**, or **Nobody** |
| **Due within (hours)** | Only tickets with a service-level target due within this many hours, or overdue |
| **Tickets in order of** | **Recently updated first**, **Newest first**, **Soonest due first** or **Most urgent first** |

A view never shows more than the person looking may see: it only narrows their own list.

A new site starts with views such as **My open tickets** and **Unassigned**.
