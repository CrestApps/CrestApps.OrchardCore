When a request needs a visit, turn it into a work order from the ticket.

| | |
| --- | --- |
| **Menu** | Service Desk > Tickets, then a ticket's **Work order** panel |
| **Permission** | Edit tickets on the ticket's desk, and **Manage work orders** |
| **Feature** | Tickets and Work Orders |

<AskYourAdmin />

## Steps

1. Open the ticket.
2. Under **Work order**, choose a type and, if you like, a priority.
3. Select **Create a work order**.

The work order gets the ticket's subject, first message, account and requester, and shows under **Links**. When the work order is completed or canceled, the ticket's conversation says so, as an internal note, so you know to answer the requester. The ticket's status is left to you.

See [Work orders](../field-service/work-orders.md) for what happens next.
