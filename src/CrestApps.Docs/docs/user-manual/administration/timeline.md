Many record pages, such as a work order or an order, have a **Notes** card: the record's timeline. It lists, newest first, the notes people wrote, the comments, and the things that happened to the record, such as a change of status. Use it to keep everyone who works on the record up to date.

| | |
| --- | --- |
| **Menu** | On the page of the record, such as **Field Service > Work Orders** or **Commerce > Orders** |
| **Permission** | Whatever lets you see and work on that record; **Redact timeline entries** to redact |
| **Feature** | Timeline, turned on by the features that use it |

<AskYourAdmin />

## Add a note

1. Open the record and find the **Notes** card.
2. Type your note in the box.
3. Select **Add note**. A note is seen only by the people who work on the record.

Some records also offer **Add comment**. A comment is seen by everyone who may read the record, which can include the customer.

## Mention a colleague

Type `@` followed by a colleague's user name, such as *@maria*, anywhere in a note. When you add it, they get a notification that links to the record. A colleague who may not see the record is not told.

## Read the timeline

Each entry shows when it was written (in your time zone), who wrote it (or **The site** for something the site did), and, for a change, the field and its value before and after. An **Internal** badge marks a note only the team sees.

## Redact text

When a note holds something that must not be kept, such as a card number, select **Redact** on it and confirm. The text and any attached files are removed for good; the entry stays and shows that it was redacted. You need the **Redact timeline entries** permission.
