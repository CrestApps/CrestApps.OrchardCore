# Appendix D - Test coverage gap list (generated 2026-09-06)

Heuristic: every non-model, non-interface class under the moving `Core` projects and the framework-eligible module folders (`Services`, `Handlers`, `Endpoints`, `BackgroundTasks`, `Hubs`, `Tools`) was matched against `tests/**/<ClassName>Tests.cs`. A class listed here has **no test file named after it**. Many are covered by tests with other names (for example `ContactCenterRecordingAndMonitoringTests` covers several services, `DialerModeIntegrationTests` covers the dialer strategies), so this is the starting list for the Phase 0 coverage audit (P0.1), not a verdict. The audit replaces this heuristic with measured coverage (coverlet) and records, per class, the test that exercises it.

Rule for P0.1: a class may move in Phase 1 only when it has (a) a named unit test or (b) a recorded covering test in the audit table, and its public behaviour is pinned by at least one assertion per public method that framework consumers can call.
